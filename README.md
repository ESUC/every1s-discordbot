# Every1s Discord Bot

## Use
/every1s @Role @Role - Creates pairings with multiple roles

/every1s roles: @Volunteers

/reset - Resets the pairings and leaderboard

/leaderboard - shows the leaderboard

/submit @Person @Person @Person location - submits for one pairing points per different location
    Online - 1 point
    On campus - 2 points
    Off campus - 3 points

## Output

Group 1: @xxx + @xxx
Group 2: @xxx + @xxx
Group 3: @xxx + @xxx + @xxx
